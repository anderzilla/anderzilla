# Kit editorial com imagens das fontes

60 pastas, uma por notícia. Cada pasta contém capa JPEG, galeria quando disponível, créditos e textos PT/EN para redes. Preserve os créditos e o contexto editorial. As imagens sem fotografia oficial adequada mantêm a arte original identificada.

Os links dos textos sociais usam o domínio canônico AnderZilla; o site está publicado em https://anderzilla.com. Nenhuma postagem foi enviada às redes sociais.
